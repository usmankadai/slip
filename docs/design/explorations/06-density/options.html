Exploration 06: density

Compact is the default: 24px rows and 12px text, fixed in the identity. This page is about the other setting. What should "comfortable" change, and what must stay the same in both? Each option shows the same eight real rows from the generated rail schedule, compact above and comfortable below.

The identity (D16) already says comfortable is 32px rows with 13px text. That is option B. A and C are drawn to test whether it is the right definition.
