Exploration 10: the activity drawer

Three ways to show one activity in a drawer under the changes grid and Gantt, where the UI spec puts it. The spec names five parts: General, Changes, Predecessors, Successors and Trace. The question is how a planner reaches them, and what they see first when they select a row and ask "what happened to this one?".

Drawn at 1280px with the drawer 300px tall, under four rows of the grid. The data comes from the engine's existing activity request, which returns the activity in both updates, its first 30 predecessors and successors in each, and how far it moved. Nothing new is computed.
