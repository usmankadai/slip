Exploration 05: agent steps

The assistant answers by calling tools against the loaded schedule, then writing. A planner has to be able to trust the answer, or see where not to, without reading the working. Two questions: how much of the working to show by default, and how a grounded statement looks different from one that is not.

The rules that are not choices: the assistant never states a date, duration or float that did not come from a tool result; an activity code it cites is checked against those results and shown as unverified when it is not there; "the data does not show this" is a designed answer, not an error.
