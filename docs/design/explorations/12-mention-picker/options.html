Exploration 12: the mention picker

The product spec says only that # opens an activity, WBS or code picker in the assistant's input. The planner wants to point at the activity they mean without copying its code, at 350,000 activities, where a name such as "Install catenary" may match a thousand rows. What is picked must reach the model as a code it can look up, and the planner must still be able to read their own question.

Each option is drawn in the assistant panel at its real width (420px), against the 1,000 activity fixture. The search is the grid's own engine search over codes and names, so no new index is needed.
