Identity: colour value options

D16 fixed the character of the identity (warm neutral surfaces, one violet accent, warm for late, blue for early) and left the exact values open. This page proposes values and checks them. Contrast ratios are computed on the page from the values shown, so they cannot go stale.

Values proposed by Claude for Usman to accept, change or reject. The decision goes in the README beside this file.

Seen as

Thresholds: 7:1 for primary text (the identity's own rule), 4.5:1 for other text (WCAG AA), 3:1 for marks and borders that carry meaning. Colour-blind views use the Machado, Oliveira and Fernandes (2009) simulation at full severity.
