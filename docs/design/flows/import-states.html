Import: the states of layout A

Layout A (two slots side by side) was chosen on 11 November 2026. This page draws every moment it has to handle, still as boxes and labels. Wording in quotation marks is proposed copy.

The planner's question: "Did my files load, and can I trust what loaded?"
Rule from the spec: warnings never block. Only a file that cannot be read at all is an error.

Drawn by Claude for Usman to review. Hatched boxes mark a choice that is still open; they are listed at the end.

Two cases, shown together
They would rarely happen at once. Each is a question asked inside the slot, and Compare updates waits for it.
Project picker
Data date and activity count beside each name, so the right one can be told apart. If update B is already read, the project with the same name is chosen in advance.
Incomplete file
The safe answer is the main button. Using the file is allowed, is the planner's choice, and is written to the audit log. The file stays marked incomplete everywhere afterwards.

One line, five wordings
The line always states what Slip checked, in a full sentence, so the sound case and the unsound cases read the same way.
Warn, do not block
In every case but "same file twice" Compare updates stays live, since the spec says warnings never block. The line's own button is the suggested fix and becomes the main button on the screen.
Wrong order
When both files are dropped at once this cannot happen, because Slip orders them. It is for files chosen one at a time.
Same data date
Not in the spec. Added here because it happens (a resubmitted update) and the line would otherwise say something odd. Usman to confirm.
